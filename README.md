# My Studio

My Studio 是研究生每日工作的入口網站，用於集中整理研究進度、專案資料、學習資源與常用工作工具。專案目標是提供一個穩定、清楚且可持續擴充的研究工作平台，協助使用者快速進入工作狀態並掌握研究脈絡。

## 專案目標

My Studio 旨在整合研究、專案與學習資源，成為研究生日常工作流程的主要入口。透過 Dashboard、研究紀錄、專案管理與文件閱讀等模組，讓使用者能夠更有效率地追蹤進度、整理想法、管理成果，並在不同工作情境之間保持一致的操作體驗。

## 功能特色

以下功能為目前或未來預計整理的核心模組：

- Dashboard
- Research Log

- Paper Reader
- Slab Builder
- Weekly Report

## 技術架構

本專案預計以以下技術作為主要架構：

- HTML
- CSS
- JavaScript
- Cloudflare Pages

## 專案結構

目前專案結構以靜態網站與研究資料模組為主：

- `index.html`：網站主要頁面結構。
- `style.css`：全站樣式與版面配置。
- `app.js`：前端互動邏輯。
- `projects/`：專案相關資料與內容。
- `research-log/`：研究紀錄相關資料與內容。
- `wrangler.jsonc`：Cloudflare Pages 或 Workers 相關設定。
- `README.md`：專案說明文件。
