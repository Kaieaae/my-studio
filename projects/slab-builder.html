Project 01

Generic Slab Builder

Interactive Surface Slab Generator

一個將表面模型建立流程整理成清楚步驟的研究工具，目標是讓計算材料研究者能更快從 bulk structure 轉換到可驗證、可重現、可投入 VASP 計算的 slab model。

Project Overview

Generic Slab Builder 聚焦於表面科學常見的前處理工作：切面、真空層、超晶胞、固定底層與結構檢查。它把容易出錯的手動步驟轉成一致的互動流程。

Problem

Slab 建模常需要在多個工具與格式之間來回切換。Miller Index、真空厚度與原子層固定若沒有清楚紀錄，後續計算很難重現。

Solution

透過單一介面輸入結構與參數，系統輸出可用於 VASP 的模型，並在建立過程中提供基本 validation，降低研究前處理的摩擦。

Workflow

匯入 bulk crystal structure，設定 Miller Index、Vacuum 與 Supercell，指定固定底層，檢查結構合理性，最後在 3D viewer 中確認輸出。

Current Features

目前包含 slab generation、參數化設定、底層固定、輸出前驗證，以及可協助檢查模型方向與層狀結構的互動式檢視。

Validation

工具會檢查真空層、層數與基本結構輸出，讓研究者在送入計算前先排除常見的幾何設定錯誤。

Current Limitations

目前仍以明確參數控制為主，對特殊表面重構、缺陷與吸附物的支援會在後續版本中逐步擴充。

Future Development

未來會加入更完整的結構模板、批次輸出、計算任務串接，以及更細緻的錯誤提示，使工具更貼近實際研究工作流。
